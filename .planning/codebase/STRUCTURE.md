## Directory Purposes

**src/**
- Purpose: All application source code
- Contains: React components, hooks, logic, styles
- Key files: App.jsx (routes), firebase.js (config), useTournament.js (state)

**src/components/**
- Purpose: React component tree organized by phase (setup, play, shared)
- Contains: 10 JSX files split by tournament phase and reusability
- Key pattern: Setup components edit tournament config; Play components manage live matches

**src/components/setup/**
- Purpose: Tournament configuration before play starts
- Contains: SetupAmericano (individual player input), SetupPairs (duo configuration)
- Dependency: Calls `persist()` from `useTournament` on config changes (debounced 600ms)

**src/components/play/**
- Purpose: Live tournament display and score input
- Contains: 4 Play* components (one per tournament type)
- Pattern: Each imports its logic module (americano.js, relampago.js, etc) and shared UI

**src/components/shared/**
- Purpose: Reusable UI components across all tournament types
- Contains: Layout (THeader), navigation (Tabs), modals (SimpleModal), tables (PairStandings)
- Used by: All setup and play components

**src/hooks/**
- Purpose: Custom React hooks
- Contains: useTournament.js (only hook currently)
- Responsibility: Firestore listener, version control, persist with rollback, auth state

**src/logic/**
- Purpose: Pure functions for tournament rules and calculations (no side effects)
- Contains: 8 modules: 4 format-specific (americano, relampago, mundialito, pozo), 2 utility (stats, utils), 2 initialization (constants, initTournament)
- Pattern: All functions are deterministic; no Firebase access (state passed as arguments)
- Tests: 3 test files (americano.test.js, pozo.test.js, stats.test.js)

**src/logic/constants.js**
- Purpose: Shared constants and legacy style helper
- Contains: TOURNAMENT_TYPES array, TOURNAMENT_RULES object, B() function
- Note: B() is deprecated (inline styles); new code uses Tailwind

**dist/**
- Purpose: Build output from Vite
- Generated: Yes (npm run build)
- Committed: No (.gitignore)

## Key File Locations

**Entry Points:**
- `src/main.jsx`: React DOM entry point, wraps App with BrowserRouter
- `src/App.jsx`: Route dispatcher using React Router (/, /torneo/:code, /panel, /perfil)
- `src/index.html`: HTML template for Vite build

**Configuration:**
- `src/firebase.js`: Firebase initialization, exports db and auth
- `vite.config.js`: Vite bundler config
- `src/index.css`: Tailwind import + @theme CSS variables (colors)
- `.env.local` (not in repo): Contains VITE_FIREBASE_API_KEY

**Core Logic:**
- `src/hooks/useTournament.js`: Central state, listener, persist, auth
- `src/logic/initTournament.js`: Tournament schema initialization
- `src/logic/americano.js`: Americano matchmaking (largest logic file)
- `src/logic/relampago.js`: Double-elimination bracket

**Testing:**
- `src/logic/americano.test.js`: Unit tests for Americano logic
- `src/logic/pozo.test.js`: Unit tests for Pozo logic
- `src/logic/stats.test.js`: Unit tests for standings calculation

## Naming Conventions

**Files:**
- Components: PascalCase — `PlayAmericano.jsx`, `SetupPairs.jsx`
- Hooks: camelCase with `use` prefix — `useTournament.js`
- Logic/utilities: camelCase — `americano.js`, `utils.js`, `stats.js`
- Tests: module name + `.test.js` — `americano.test.js`

**Directories:**
- Component folders: lowercase plural — `components/play/`, `components/setup/`, `components/shared/`
- Logic folder: lowercase — `logic/`
- Hooks folder: lowercase — `hooks/`

**Functions:**
- Components: PascalCase — `export default function PlayAmericano() {}`
- Logic: camelCase — `precomputeAllRounds()`, `buildFirstRoundAmericano()`
- Utilities: camelCase — `shuffle()`, `pk()`, `genCode()`

**Variables:**
- Constants: UPPER_SNAKE_CASE — `TOURNAMENT_TYPES`, `SCORING_OPTIONS`, `LEVELS`
- State: camelCase — `localName`, `isAdmin`, `currentRound`
- Refs: camelCase + Ref suffix — `debRef`, `nameInputRef`, `verRef`

**Types/Schemas:**
- No TypeScript, but objects follow patterns:
  - Tournament: `{ ver, status, type, ownerUid, config, players, rounds, currentRound, ... }`
  - Player (Americano): `{ id, name, level }`
  - Pair (other types): `{ id, p1, p2 }`
  - Court: `{ pairA, pairB, scoreA, scoreB, saved }`

## Where to Add New Code

**New Tournament Format:**
1. Create `src/logic/{formatname}.js` with main functions:
   - `buildInitial{FormatName}()` for schema (call from `initTournament.js`)
   - `buildFirstRound{FormatName}()` if applicable
   - `advance{FormatName}()` for progression
2. Create `src/components/setup/Setup{FormatName}.jsx` or reuse `SetupPairs.jsx`
3. Create `src/components/play/Play{FormatName}.jsx` with render logic
4. Add entry to `TOURNAMENT_TYPES` array in `src/logic/constants.js`
5. Add conditional render in `src/TournamentPage.jsx` (lines 72-82)

**New Setup Feature (e.g., advanced player options):**
- Location: `src/components/setup/{SetupAmericano|SetupPairs}.jsx`
- Pattern: Add local state (immediate) + debounced `persist()` call (600ms)
- Example: Adding skill tier display — add to LEVELS array, render in player list

**New Play Feature (e.g., undo last result):**
- Location: `src/components/play/Play{Format}.jsx`
- Pattern: Modify `currentRound` array and call `persist()`, logic layer not needed
- Example: "Edit Score" button at line 62-73 in PlayAmericano

**Shared UI Component:**
- Location: `src/components/shared/Components.jsx` (if generic) or new file
- Pattern: Export pure function component, take props for data and callbacks
- Example: `export function RoundHeader({ roundNum, sittingOut }) { ... }`

**Utility Function:**
- Location: `src/logic/utils.js` (general) or module-specific file
- Pattern: Pure function, no side effects, no Firebase
- Example: `export const formatScore = (a, b) => a > b ? `${a}-${b} ✓` : `${a}-${b}`

**Test:**
- Location: `src/logic/{modulename}.test.js`
- Framework: Jest (configured in package.json)
- Pattern: `describe()` blocks, `it()` test cases, arrange-act-assert
- Run: `npm test`
